## Brief Description of the Program

This program finds the **Greatest Common Divisor (GCD)** of two non-negative integers. It uses the **Euclidean Algorithm** and recursion to calculate the answer. The program also shows the recursive calls until it reaches the base case.

## Programming Language Used

**Java**

## Instructions for Compiling and Running the Program

1. Save the program as `RecursiveGCD.java`.
2. Open Command Prompt or Terminal.
3. Go to the folder where the Java file is located.
4. Compile the program:

```text
javac RecursiveGCD.java
```

5. Run the program:

```text
java RecursiveGCD
```

6. Enter two non-negative integers when the program asks for them.

## Sample Input

```text
Enter first non-negative integer: 89
Enter second non-negative integer: 10
```

## Sample Output

```text
Recursion trace:
gcd(89, 10), a % b = 9
gcd(10, 9), a % b = 1
gcd(9, 1), a % b = 0
gcd(1, 0) -> 1 (base case)
GCD = 1
```
